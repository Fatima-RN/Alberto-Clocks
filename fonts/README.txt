Offline fonts (optional)
========================
The site loads Manrope and Cormorant Garamond from Google Fonts when you are online.
To make them work without the Internet too:

1. Open https://gwfh.mranftl.com/fonts (google-webfonts-helper) in a browser.
2. Pick "Manrope" (weights 400, 500, 700) and "Cormorant Garamond" (weights 500, 600).
3. Download the WOFF2 files.
4. Save them in this folder with exactly these names:
     Manrope-Variable.woff2
     CormorantGaramond-SemiBold.woff2
   (css/base.css already points to these two names.)

DSEG7Classic-Regular.woff2 (the digital clock font) is already here.
